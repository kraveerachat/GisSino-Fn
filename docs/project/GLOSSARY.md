# Glossary

| Term | Meaning |
|---|---|
| Account / Wallet | A place money sits: bank, e-wallet, cash, or credit card. (กระเป๋าเงิน) |
| Ledger | The list of money movements from which balances are computed. |
| Transfer | A move between the user’s own accounts; never an expense. |
| Adjustment | An explicit entry that fixes a mismatch with the real bank balance. |
| Needs details | An entry saved quickly and described later. (รอเติมรายละเอียด) |
| Safe to spend | Money available minus obligations not yet paid. (เงินที่ใช้ได้จริง) |
| Obligation | An installment, credit-card payment, bill, or subscription due on a date. (ภาระ) |
| Party | A group whose members see shared habit statistics. (ปาร์ตี้) |
| Visibility level | Private / Status only / Full, selected per member. |
| Freeze | An item that automatically protects a streak when a day is missed. (วันพัก) |
| XP / Level | Habit points and the level derived from them. |
| PWA | A web app installed on the home screen. |
| Tunnel | Cloudflare Tunnel: an outbound-only connection from the server to Cloudflare. |
| BOLA / IDOR | Accessing another user’s object by guessing an ID; prevented by owner checks. |
