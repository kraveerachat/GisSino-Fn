# GisSino design foundation

The owner's written brief is the visual authority for this local preview. The supplied blue-enamel Image A now governs the three redesigned screens. References B/C and authoritative project documents are still missing; their contents are not inferred.

Use opaque, manufactured enamel surfaces with a cool off-white ground, restrained directional sheen, a fine bevel, contact shadows, and recessed control wells. Light appearance is Sky Blue & Cobalt Enamel; dark appearance is Graphite & Amber. One dominant accent per theme. Semantic success/warning colors convey status only.

This is an Operate surface: balances, quick actions, upcoming obligations, and transaction reading order govern composition. The latest navigation decision supersedes the old five-slot mobile arrangement: Home / Wallet / Activity / More capsule plus a separate right-hand Add circle. Bills and Party live in More. Preserve Home's financial content and visual hierarchy. The attached interaction video is absent; the written floating-island specification guides the interaction without a video-fidelity claim.

The signature interaction is the separate tactile Add control on the right opening a native modal bottom sheet. Pressed surfaces settle rather than glow. A small no-spend seal provides the single celebratory moment, without changing a real streak.

Self-host Noto Sans Thai. Use readable Thai/English copy and tabular financial numerals. Small content can wrap; no fixed phone-width frame. CSS custom properties own themes and material colors. Mobile uses bottom navigation; wide layouts retain the existing rail styling, with Wallet added.

Keep the sample-data banner visible. Every simulated financial action must explicitly say it is not saved. Party never shows account balances or transaction items. See docs/design for the detailed contract and verification limits.
